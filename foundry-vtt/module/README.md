# Stream Deck Bridge

Lets the **Foundry VTT** Stream Deck plugin (`com.benwyrosdick.foundry-vtt`)
control this world: macros, scenes, the selected token, the combat tracker,
playlists and sounds, pause, dice, roll tables, chat, scene darkness and
sidebar tabs. Keys show live state — scene thumbnails, the playing track, the
current round — drawn on the Stream Deck.

1. Install the Foundry VTT plugin on the computer the Stream Deck is plugged into.
2. Enable this module, then in *Configure Settings → Stream Deck Bridge* paste
   the **Pairing code** shown in any Foundry VTT key's settings in the Stream
   Deck app.

Full documentation: <https://github.com/benwyrosdick/streamdeck-plugins/tree/main/foundry-vtt>
