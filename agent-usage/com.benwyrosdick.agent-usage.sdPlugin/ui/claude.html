Claude Code renews its login while it runs; when it hasn't run for a few hours the key shows Expired. With this on, the plugin renews the login itself and keeps its own copy in Stream Deck's settings (Claude Code's credentials are never changed). Anthropic may retire Claude Code's copy when the plugin renews, in which case Claude Code asks you to sign in again. Needed if Claude Code runs on a claude setup-token token, which can't read plan usage.
